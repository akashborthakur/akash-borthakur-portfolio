30-day activation plan / 02

One account. Multiple relevant touches.

Six five-day sprints. Channel activity is sequenced around account intent and buying context, not a generic “blast everyone” cadence.

Days 01–05 / Research

Build the account thesis

Tier ICP-fit accounts, map the buying committee, identify the trigger and write a one-sentence hypothesis for each tier.

Clay enrichment
HubSpot CRM
Output: prioritised account list + persona map

Find a reason to engage

Review website intent and topic signals. Match a message and asset to the account’s likely business problem.

LinkedIn research
Output: account-specific message hypothesis
Days 11–15 / First touch

Start a useful conversation

Coordinate a concise email, relevant LinkedIn interaction and one useful proof point. Suppress irrelevant or opted-out contacts.

Close the loop

What good looks like

Evidence, not activity theatre

At day 30, the readout should show which account tiers progressed, which roles engaged, what created meetings, where the funnel stalled and what test changes next month.

Operator’s note

Personalisation is an operating choice.

The framework works when each channel carries the same customer hypothesis forward. Keep sales ownership explicit, honour suppression and consent rules, and use response signals to change the plan—not just to add more touches.
